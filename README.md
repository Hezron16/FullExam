# HandaPH Website Project

## Project overview
HandaPH is an educational disaster-preparedness website for Filipino households and communities. It is aligned with UN Sustainable Development Goal 11: Sustainable Cities and Communities.

## How to open
1. Extract the `HandaPH_Final.zip` folder.
2. Open the folder in Visual Studio Code or another code editor.
3. Open `index.html` in a web browser. For a smoother development workflow, use VS Code Live Server if available.
4. Keep the `css`, `js`, `images`, and `videos` folders in the same project folder. Do not rename or separate them.

## Pages
There are 18 HTML pages: Home, About, Choose a Hazard, Checklist, Kit Guide, Family Plan, Typhoon, Flood, Earthquake, Fire, Landslide, Volcanic Activity, Before a Disaster, During a Disaster, After a Disaster, Community Preparedness, Learning Videos, and References.

## Technology
- HTML5 semantic structure
- CSS3 (responsive layout; no Bootstrap or CSS framework)
- Basic JavaScript for checklist saving, mobile navigation, and family-plan form interactions

## Media
- 10 original SVG illustrations in `images/`
- 5 original MP4 learning clips in `videos/`
- Media created specifically for this HandaPH student project. External content is cited on `references.html`.

## Accessibility and usability
- Skip-to-content link
- Semantic landmarks and heading structure
- Descriptive image alternative text
- Keyboard-visible focus indicators
- Responsive layout and readable contrast
- Reduced-motion preference respected
- Labeled form controls and accessible live updates

## Important limitations
This is an educational project, not a live emergency alert service. The family-plan form only displays entries during the current page session. Checklist progress is stored in the current browser on the current device. The website does not send data to a server, provide real-time hazard alerts, or identify nearby evacuation centers. Users must follow official advisories and local authorities.
